# China Cloud OCR for Odoo 19 Expense (国内在线发票 OCR 报销模块)

[![Odoo Version](https://img.shields.io/badge/Odoo-19.0-blue.svg)](https://www.odoo.com/)
[![License](https://img.shields.io/badge/License-LGPL--3-green.svg)](https://www.gnu.org/licenses/lgpl-3.0.html)

本模块专为 **Odoo 19 Enterprise** 设计，替换官方的 IAP OCR 提取服务，接入国内主流云服务商 OCR（百度智能云、腾讯云、自定义 REST API），实现增值税发票、通用发票与各类票据的自动识别、结构化提取与智能填报。同时提供强大的**邮件报销标题自动解析**与**智能防覆盖合并机制**。

---

## ✨ 核心特性

1. **国内主流云 OCR 支持**：
   - **百度智能云**：增值税发票识别（`vat_invoice`）与 Access Token 自动维护。
   - **腾讯云 OCR**：官方 SDK 直连，支持增值税发票识别（`VatInvoiceOCR`）并具备智能结构化识别（`SmartStructuralOCR`）平滑回退。
   - **自定义 REST API**：灵活对接企业私有化部署或自建的 OCR 识别服务。
   - **零 IAP 扣费**：直接使用自有云服务商账户，彻底摆脱官方 IAP 点数限制。

2. **邮件报销标题智能解析**：
   通过邮件别名发送报销邮件时，系统自动从邮件主题中解析并提取：
   - **费用分类**：支持中括号编码匹配（如 `[FOOD_BIZ]`、`[TRAVEL]`），自动对应报销产品。
   - **金额与币种**：智能提取数字金额，避免年份误识别为金额。
   - **费用日期**：支持在标题中任意位置直接指定日期（如 `2024-12-05`、`2024/12/05`、`2024.12.05` 或 `[2024-12-05]`）。
   - **干净费用描述**：自动从标题剥离编码、金额与日期，生成纯净的报销说明。

3. **智能合并与防覆盖策略**：
   - **标题指定日期优先**：若邮件标题中已明确指定费用日期，发票附件 OCR 识别时**绝不会覆盖**该日期。
   - **OCR 实际日期兜底**：若邮件标题未指定日期（初始为邮件收取当天日期），OCR 成功提取到发票实际开票日期后，**自动更新覆盖**初始的当天占位日期。

## 📧 邮件报销标题示例

邮件标题格式非常灵活，支持以下任一书写习惯：

```text
餐饮消费 [FOOD_BIZ] 357.00 2024-12-05
2024-12-05 餐饮消费 [FOOD_BIZ] 357.00
餐饮消费 [FOOD_BIZ] 357.00 [2024-12-05]
差旅住宿 [HOTEL] 450.00 2024/11/20
办公耗材 [OFFICE] 88.00 2024.10.15
```

## ⚙️ 配置说明

1. 安装依赖库（若使用腾讯云）：
   ```bash
   pip install tencentcloud-sdk-python requests
   ```
2. 在 Odoo 后台进入：**【设置 -> 费用】**
3. 找到 **【国内在线 OCR 配置 (China Cloud OCR)】**：
   - 选择服务商（百度智能云 / 腾讯云 / 自定义 API）
   - 填写对应的 `API Key / SecretId` 与 `Secret Key / SecretKey`
   - 保存即可生效。
